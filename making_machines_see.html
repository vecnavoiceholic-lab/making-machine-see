What is Computer Vision?

  • Branch of AI that enables machines to see, interpret, and act on visual data
  • Teaches computers to understand images the way humans do
  • Uses mathematical algorithms — not actual eyes or biological vision
"Computer Vision is a field of AI that enables machines to derive meaningful information from digital images and videos."
Key Terms — Chips

Core Idea: Computers do not see images the way humans do. They see grids of numbers. Each number = a pixel value. All of Computer Vision is built on interpreting those numbers intelligently.

Pixel — Smallest Unit of an Image

  • Every image = a 2D grid of pixels
  • Each pixel stores a number (intensity or colour value)
  • More pixels = higher resolution image
  • A 100×100 image has 10,000 pixels

Image Types

Grayscale
  • 1 value per pixel
  • Range: 0 (black) → 255 (white)
  • Shades of grey only
  • e.g. X-ray, CCTV footage
RGB (Colour)
  • 3 values per pixel (R, G, B)
  • Each channel: 0–255
  • (255, 0, 0) = pure red
  • e.g. photos, videos

Why Convert to Grayscale?

  • Reduces data: 3 channels → 1 channel
  • Faster processing, less memory usage
  • Colour is often irrelevant for shape/edge detection
  • Simpler mathematics for feature extraction
"Grayscale reduces image complexity and improves processing efficiency by removing redundant colour information."

Occlusion

  • When an object is partially hidden in an image
  • Example: face covered by a mask, car behind a tree
  • Real-world images are rarely perfect — occlusion is common
  • Key challenge: models must still recognize partially visible objects
"Occlusion handling improves model robustness in real-world conditions."

Segmentation Types

  • Semantic Segmentation — all objects of same class get same colour label (all cars = blue)
  • Instance Segmentation — each individual object gets a unique label (Car 1, Car 2, Car 3…)

Basic Preprocessing Steps

  • Resizing — standardise image dimensions (e.g. 224×224)
  • Normalisation — scale pixel values to 0–1 range
  • Noise removal — blur/filter to remove unwanted artifacts
  • Grayscale conversion — reduce from 3 channels to 1
  • Thresholding — convert to binary (black/white) image

Feature Extraction — What Machines Look For

EdgesBoundaries between regions; areas of sharp intensity change
CornersPoints where two or more edges meet sharply
TexturesRepeating patterns within a region (e.g. fur, fabric)
ShapesGeometric forms — circles, rectangles, curves
Example: A face = jaw edges + eye curves + nose shape → combined into a "face" feature map

Challenges in Computer Vision

  • Lighting conditions — too dark or overexposed images degrade accuracy
  • Occlusion — partially hidden objects are harder to classify
  • Background noise — cluttered scenes confuse models
  • Scale variation — same object at different sizes or viewing angles
  • Real-time processing — speed vs accuracy trade-off
Real-life Examples (Detailed)
📱
Face Unlock on Smartphones
Camera captures face → converts to pixel map → grayscale preprocessing → extracts facial features (jaw, eyes, nose) → matches against stored feature template → unlocks device. Uses both Classification and Detection.
🏥
Medical Imaging (X-ray / MRI Analysis)
CV models detect tumours, fractures, or anomalies in medical scans. Grayscale images are processed to highlight unusual regions. Often faster and more consistent than manual review by radiologists.
